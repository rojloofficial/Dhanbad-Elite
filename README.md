# Dhanbad Elite

A modern, responsive, performance-optimized VIP directory web application for Dhanbad, Jharkhand.

## Features

- **Responsive Design**: Fluid layout from 320px mobile screens up to 4K displays with zero horizontal scroll overflow.
- **Fast Filtering & Real-time Search**: Multi-category tabs (VIP Elite, College Model, High Profile, etc.), locality chips (Saraidhela, Bank More, Hirapur, etc.), and instant debounced search.
- **Direct Concierge Integration**: One-click direct calling (`tel:8252377842`) and instant Telegram concierge chat (`https://t.me/i_am_turtle`).
- **SEO & Structured Data**: Semantic HTML5 markup, Schema.org `FAQPage` and `LocalBusiness` JSON-LD schemas, and city companion guide.
- **Verified Reviews & Interactive Modals**: Full companion profile modal viewer with keyboard navigation and accessible focus management.

## Tech Stack

- **HTML5 & CSS3** (Vanilla, optimized custom property design system)
- **Vanilla JavaScript (ES6+ Modules)**
- **Vite** (Build tool & dev server)

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/rojloofficial/Dhanbad-Elite.git

# Navigate into the project directory
cd Dhanbad-Elite

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Production Build

```bash
npm run build
```
